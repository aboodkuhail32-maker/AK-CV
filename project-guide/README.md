# AK-CV — Project Guide

This folder explains everything in this repository: what was made, what tools
and tech were used, and how each part works.

> **Note:** This repository does **not** contain any Roblox game files
> (no `.lua` scripts, no `.rbxl` / `.rbxm` places or models). The only thing
> ever committed here is the **"-AK-" Roblox Developer CV website**. If you
> want your actual game documented, export your scripts/models from Roblox
> Studio and add them to the repo, and they can be explained the same way.
